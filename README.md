# Stirling
Stirling is an official Pixar asset derived from the Finn McMissile character in Pixar's Cars 2 and designed to showcase MaterialX. The asset was authored using MaterialX base building blocks and therefore does not use monolithic materials such as Standard Surface and OpenPBR.

Stirling comes in two openUSD variants:
- Real Time: PNG raster format. Textures use a traditional sRGB color space with a maximum resolution of 2K. Typical in web or game engines.
- RenderMan: TEX mipmapped format. Textures use a OpenColorIO Aces color space with a maximum resolution of 4K. Typical in feature animation and visual effects.
